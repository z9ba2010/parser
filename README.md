# Sport, Supplements & Events Hub API ⚡

Масштабируемый мультидоменный бэкенд, парсер и поисковая система, объединяющая:
1. **Каталог спортивной экипировки и обуви** с системой **Visual Search** (распознавание кроссовок по фото через Gemini Vision API).
2. **Каталог спортивного питания и БАДов** с фильтрацией по целям (набор массы, сушка, выносливость, восстановление, суставы).
3. **Единый агрегатор спортивных событий РФ** (забеги, марафоны, трейлы, триатлон Ironstar, гонки с препятствиями «Лига Героев», велоспорт) с гео-фильтрацией по радиусу и регионам.
4. **Документированный REST API** (OpenAPI / Swagger) для интеграции с мобильными приложениями (например, **MaxFunFit** на iOS/Android).
5. **Интерактивный веб-дашборд / тестбенч** для наглядного тестирования всех функций и визуального поиска прямо в браузере.

---

## 🛠 Технологический стек

- **Бэкенд:** Python 3.11+, FastAPI (асинхронный, высокая производительность, автоматическая валидация через Pydantic v2).
- **База данных:** PostgreSQL 16 + PostGIS (для геоданных и пространственных запросов) / SQLite (для легковесного локального запуска «из коробки»).
- **AI / Computer Vision:** Google Gemini Vision API (`gemini-1.5-flash` / `gemini-2.0-flash`) с интеллектуальным отказоустойчивым анализатором.
- **Парсинг:** Модульная архитектура (`BaseParser`, `httpx`, `BeautifulSoup4`) с логированием и аудитом запусков в БД.
- **Инфраструктура:** Docker & Docker Compose (с готовым контейнером `postgis/postgis:16-3.4`).

## 🚀 Быстрый запуск

### Вариант 1. Локальный запуск (Python)

1. **Клонируйте репозиторий и перейдите в папку:**
   ```bash
   cd "c:\AG\01. Парсер"
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **(Опционально) Настройте API-ключ Gemini Vision:**
   Создайте файл `.env` на основе `.env.example`:
   ```ini
   GEMINI_API_KEY="ваш_api_ключ_из_google_ai_studio"
   ```
   *(Если ключ не указан, сервис использует встроенный интеллектуальный эмулятор, гарантирующий 100% работоспособность поиска и тестов).*

4. **Запустите сервер:**
   ```bash
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

5. **Откройте в браузере:**
   - **Интерактивный дашборд:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   - **Swagger UI (OpenAPI):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
   - **ReDoc документация:** [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## 📱 Функционал модулей и API

### Модуль 1: Экипировка и обувь
- `GET /api/v1/apparel` — фильтрация по `brand`, `purpose` (бег, трейл, кроссфит, шоссе), `gender`, `subcategory`, мин./макс. цене, наличию, поисковому запросу.
- `GET /api/v1/apparel/brands` — список всех доступных брендов в каталоге.
- `GET /api/v1/apparel/{id}` — карточка товара (характеристики, технологии, дроп, вес, ссылки на покупку в магазинах RunLab, Спортмастер, Lamoda и др.).
- `POST /api/v1/apparel` — ручное или программное добавление товара.

### Модуль 2: Визуальное распознавание по фото (Visual Search)
- `POST /api/v1/vision/recognize` (Multipart Form-Data):
  - Принимает фотографию обуви или экипировки прямо с камеры смартфона пользователя.
  - Нейросеть (Gemini Vision) анализирует снимок: распознает силуэт, логотип бренда, геометрию подошвы, материалы и расцветку.
  - Поисковый движок сопоставляет результат с каталогом БД и возвращает карточку с точным совпадением, ссылками на маркетплейсы, характеристиками и альтернативными похожими моделями.
- `POST /api/v1/vision/recognize-url` (JSON):
  - Принимает ссылку на картинку в сети.

### Модуль 3: Спортивное питание и БАДы
- `GET /api/v1/supplements` — каталог с фильтрацией по:
  - Категориям (`protein`, `creatine`, `isotonics`, `vitamins`, `omega-3`, `bcaa`).
  - Целям приема: `выносливость` (циклические виды), `набор массы`, `сушка`, `восстановление`, `суставы`.
  - Формам выпуска: `порошок`, `капсулы`, `жидкость / гели`, `батончики`.
- `GET /api/v1/supplements/goals` — перечень доступных целей приема.
- `GET /api/v1/supplements/{id}` — состав, дозировка, размер порции, отзывы и цены.

### Модуль 4: Агрегатор спортивных событий РФ с Гео-поиском
- `GET /api/v1/events` — календарь стартов по всей России с параметрами:
  - `discipline`: бег / марафоны, трейлраннинг, триатлон, гонки с препятствиями (OCR), велоспорт.
  - `city` / `region`: фильтрация по регионам РФ.
  - `date_from` / `date_to`: диапазон дат.
  - **Гео-радиус:** `lat`, `lon`, `radius_km` — расчет расстояния в км от текущего местоположения пользователя до места проведения старта (например: *«показать старты в радиусе 150 км от Москвы»*).
- В каталоге собраны крупнейшие серии: «Московский Марафон», Golden Ring Ultra Trail (GRUT Суздаль), IRONSTAR Sirius Sochi, серия «Бегом по Золотому кольцу», «Гонка Героев Алабино», Казанский марафон, Gran Fondo Russia, Elbrus World Race.

### Модуль 5: Парсеры и синхронизация данных
- `POST /api/v1/parsers/run` — запуск сбора данных (`domain`: `apparel`, `supplements`, `events` или `all`).
- `GET /api/v1/parsers/jobs` — аудит и журнал выполнения задач парсинга (время, статус, количество найденных, добавленных и обновленных записей).

## 📲 Инструкция по интеграции с мобильным приложением MaxFunFit

1. **Формат ответов:** Все эндпоинты возвращают стандартизированный JSON с поддержкой постраничной навигации (`total`, `page`, `page_size`, `items`).
2. **Загрузка фото с камеры:** В мобильном приложении используйте стандартный `multipart/form-data` запрос на эндпоинт `POST /api/v1/vision/recognize`.
3. **Геолокация:** Передавайте текущие координаты GPS устройства в запросе `GET /api/v1/events?lat={user_lat}&lon={user_lon}&radius_km=100` для вывода стартов в регионе пользователя.
4. **Спецификация OpenAPI:** Готовый файл спецификации доступен по адресу `http://localhost:8000/api/v1/openapi.json`. Вы можете импортировать его в Swagger Codegen или OpenAPI Generator для автоматической генерации клиентского кода на Swift (iOS) или Kotlin (Android).
